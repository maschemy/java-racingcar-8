구현할 기능 목록 (커밋 단위 기준)

1. 입력 기능
- [ ] 자동차 이름 입력
  - [ ] 쉼표(,) 기준으로 분리
  - [ ] 이름이 비어있거나 5자 초과 시 예외 발생
- [ ] 시도 횟수 입력
  - [ ] 숫자 이외의 값 또는 0 이하일 경우 예외 발생

2. 경주 진행 기능
- [ ] 0~9 사이의 랜덤값 생성 (MissionUtils Randoms 사용)
- [ ] 랜덤값이 4 이상이면 자동차 전진
- [ ] 각 시도마다 모든 자동차 이동

3. 출력 기능
- [ ] 경주 시작 문구 출력
- [ ] 매 라운드별 이동 결과 출력
- [ ] 최종 우승자 출력 (공동 우승 가능)

4. 예외 처리
- [ ] 입력값 검증 실패 시 IllegalArgumentException 발생 후 종료
